# Mingus Sports: notes for Claude

Fantasy football site for Josh (joshwilliams332). Live at https://joshwilliams332.github.io/mingus/.
Static pages in `site/`, data built by `scripts/build_data.py` from nflverse (plus Sleeper projections when reachable).
Josh mostly checks the site on his phone, so every change gets checked at ~390px wide as well as desktop.

## How work ships
- Work on a branch, open a PR into `main`, merge it. Merging deploys via `.github/workflows/update-and-deploy.yml`
  (also runs daily at 23:17 UTC and on "Run workflow"). GitHub Pages source is "GitHub Actions".
- The deploy tags `assets/common.js` and `assets/style.css` with the commit hash, so no manual cache busting.
- `site/data/*.json` is regenerated by the deploy; don't hand-edit it.
- Shared helpers (scoring, formatting, ranks, header/footer) live in `site/assets/common.js`.

## Conventions and decisions so far
- Fantasy points are computed in the browser from raw stats (`scoreGame`), so PPR / half / standard and 4- or
  6-point pass TDs can be switched anywhere (`scoringControls`, saved in localStorage).
- **Ranks in parentheses** after stats, e.g. `717 (1st)`, via `rankTag()` in common.js. Top 5 is green.
  - Player pages: season stats ranked against the same position (players with enough games, `minGames`).
  - "Bad" stats (thrown INT, a kicker's missed FGs) still rank most = 1st, but a top-5 rank is **red**.
    A defense's INT are good (green).
  - Teams: points scored / allowed / vs implied per game among NFL teams (`teamAverages`, `rankOf`); fewest allowed = 1st.
  - Over/unders and implied team totals rank within their week and show "of N", e.g. `39.5 (12th of 14)` (`weekLineRanks`).
- **Matchup page (`game.html`)**, top to bottom: score, lines (and results once final), venue, notes, each team's
  last games ("going in" once played), then:
  - before the game: Matchup edges (offense vs defense cards);
  - after the game: Box score only (team stat comparison + passing / rushing / receiving / kicking / fantasy points,
    with a Proj column (Sleeper) or Avg (pre-game points per game) before actual FPTS, green = beat it, red = short).
  - If the score is final but nflverse hasn't published player stats yet, the edges stay up with a note.
- **Charts (`analytics.html`)**: a one- or two-week window is a noisy sample. Weak verdicts are worded about that
  window ("In Week 6 alone...") and the full-season r is shown alongside, so a stat isn't written off from one week.
- Player game log: Snap %, Opp % (carries + targets share) and Tgt % have header tooltips and a note under the table.
- Phones: player names wrap instead of overlapping tags; grid children have `min-width: 0` so wide tables scroll
  inside their card; team schedule hides O/U, Total and Pts vs implied on small screens.
